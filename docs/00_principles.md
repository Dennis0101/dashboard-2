# 제품 원칙 (절대 변경 불가)

## 1) 신뢰가 수익보다 우선

- 유저가 맡긴 자금/키/데이터의 안전이 최우선이다.
- “더 많이 거래”보다 “불필요한 거래를 하지 않음”이 우선이다.

## 2) 보안이 기능보다 우선

- 키 노출/권한 오남용 가능성이 0이 아니면 기능은 출시하지 않는다.
- 로그/모니터링/디버깅 편의보다 비밀정보 보호가 우선이다.

## 3) 투명성이 과장보다 우선

- 수익 과장 금지.
- 시스템의 상태(하고 있는 것/하지 않는 것/불확실한 것)를 항상 명시한다.

## 4) 애매하거나 위험하면 자동매매 중단

- 데이터 누락, 거래소 응답 불안정, 포지션 상태 불일치, 리스크 계산 불확실 등의 경우:
  - **진입/추가진입 금지**
  - **기존 포지션은 정책에 따라 방어적으로 정리**

## 5) 모든 트레이드는 차트에서 증명 가능

유저는 항상 다음을 직접 확인할 수 있어야 한다.

- 언제 진입했는지
- 롱/숏 방향
- 언제, 왜 종료됐는지
- 각 트레이드의 수익/손실
